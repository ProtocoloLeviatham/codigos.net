DOCUMENTACIÓN OFICIAL INTEGRADA

Manual de Uso Paso a Paso (De 0 a Fin)

Guía completa de arquitectura, despliegue y uso de cada función del panel sin depender de archivos externos.

PASO 1: Qué archivos subir a GitHub Pages y por qué no necesitas ningún JSON externo

Este archivo HTML (puedes llamarlo index.html o el nombre que quieras) ya genera su propio manifiesto web internamente por código y carga tu logo desde logo.png (con respaldo embebido automático). Por lo tanto, en tu repositorio de GitHub Pages solo necesitas subir tu archivo HTML y logo.png.

PASO 2: Cómo actualizar el Cerebro en Cloudflare Workers (paneldeestadisticas)

  1. Entra a tu panel de Cloudflare → Workers & Pages → selecciona tu Worker paneldeestadisticas.
  2. Haz clic en Edit Code arriba a la derecha.
  3. Borra el código anterior, pega el código completo del nuevo worker.js y presiona Deploy.
  4. Opcionalmente, en Settings → Triggers → Cron Triggers agrega 0 */6 * * * para que el Worker guarde snapshots de crecimiento cada 6 horas automáticamente.

PASO 3: Cómo conectar cuentas de TikTok por @usuario y que queden permanentes

El panel inicia en 0 absoluto (sin cuentas falsas ni datos inventados):

  1. En la barra superior (o en la pestaña Conectar Redes), escribe el usuario de TikTok (por ejemplo @cvstudio33) y pulsa Conectar @Usuario.
  2. El sistema consulta a tu Worker en https://paneldeestadisticas.lautybg2005.workers.dev/api/account/profile?handle=cvstudio33 (y si aún no desplegaste el Worker, usa automáticamente el gateway CORS de respaldo directo desde tu navegador).
  3. Extrae los Seguidores exactos, Likes totales, Siguiendo, Videos publicados y Foto de perfil, los guarda de forma permanente en el localStorage de tu navegador y en el KV de tu Worker, y dibuja la curva vectorial real en el gráfico.

PASO 4: Cómo funciona cada vista del Panel

  • Dashboard & Métricas: Suma en tiempo real todas las cuentas conectadas y traza el Gráfico Vectorial SVG Dinámico con animación de trazo y tooltips interactivos al pasar el mouse.
  • Conectar Redes (@ / OAuth): Permite vincular infinitas cuentas de TikTok por @usuario o iniciar el flujo OAuth 2.0 para TikTok e Instagram/Facebook.
  • Auditor de Video por Link: Pegas el enlace de cualquier video de TikTok y extrae en vivo su miniatura, título, hashtags y las estadísticas actuales de su creador.
  • Personal vs. Profesional: Incluye los 4 accesos directos oficiales para convertir un Instagram Personal en Profesional y vincularlo a una Página de Facebook cuando el Worker detecta ERR_IG_NOT_PROFESSIONAL_OR_UNLINKED.
  • Modo Sandbox & Testers: Permite alternar el switch ?sandbox=true para probar el panel con datos de prueba o abrir con 1 clic las consolas de desarrolladores de Meta y TikTok.
